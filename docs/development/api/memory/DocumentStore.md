# DocumentStore Class - Technical Context Documentation

## Overview

The `DocumentStore` class is a core component for retrieval-augmented generation (RAG) and semantic search systems. It manages a collection of documents, each with a dense embedding vector generated by an encoder model, enabling efficient similarity-based retrieval.

Files:

- `src/DocumentStore.hpp` - Header file with class declaration and interface
- `src/DocumentStore.cpp` - Implementation file with all method definitions

**Purpose:** Provide a high-level API for storing, indexing, and retrieving documents using encoder-based embeddings and cosine similarity search.

---

## Class Structure

### Document Structure

```cpp
struct Document {
    std::string id;           // Unique document identifier
    std::string text;         // Document text content
    Matrix embedding;         // Dense embedding vector [1, d_model]

};
```

## Core Operations

### Constructor

```cpp
explicit DocumentStore(std::shared_ptr<LLMEncoder> encoder);
```

- **Initializes** the store with a shared encoder for embedding generation.
- **Throws** if encoder is null.

### Add Document

```cpp
void addDocument(const std::string& id, const std::string& text,
                 const std::unordered_map<std::string, std::string>& metadata = {});
```

- **Generates** embedding for the document text using the encoder.
- **Stores** the document, embedding, and metadata.
- **Throws** if the ID already exists or text is empty.

### Remove Document

```cpp
bool removeDocument(const std::string& id);
```

- **Removes** the document by ID.
- **Returns** true if removed, false if not found.

### Retrieve Top-k Documents

```cpp
std::vector<std::pair<float, const Document*>> retrieve(const std::string& query, int k = 3) const;
```

- **Encodes** the query text to an embedding.
- **Computes** cosine similarity with all stored documents.
- **Returns** top-k most similar documents as (similarity, pointer) pairs, sorted by descending similarity.
- **Throws** if k <= 0.

### Get Document by ID

```cpp
const Document* getDocument(const std::string& id) const;
```

- **Returns** pointer to document if found, nullptr otherwise.

### Store Size and State

```cpp
size_t size() const;
bool empty() const;
```

- **Returns** number of documents or whether the store is empty.

### Clear Store

```cpp
void clear();
```

- **Removes** all documents and clears the index.

### Get All Document IDs

```cpp
std::vector<std::string> getAllDocumentIds() const;
```

- **Returns** a list of all document IDs in the store.

## Embedding and Similarity

### Sentence Embedding

- **Method:**

  ```cpp
  Matrix getSentenceEmbedding(const Matrix& encoder_output) const;
  ```

- **Description:** Uses mean pooling over the sequence dimension of the encoder output to produce a single vector representation for the document or query.
- **Input:** Encoder output matrix `[seq_len, d_model]`
- **Output:** Matrix `[1, d_model]`

### Cosine Similarity

- **Method:**

  ```cpp
  float cosineSimilarity(const Matrix& emb1, const Matrix& emb2) const;
  ```

- **Description:** Computes cosine similarity between two embedding vectors. Returns a value in [-1, 1].
- **Input:** Two matrices `[1, d_model]`
- **Output:** Similarity score (float)

## Example Usage

```cpp
#include "DocumentStore.hpp"
#include <memory>

std::shared_ptr<LLMEncoder> encoder = ...; // Initialize encoder
DocumentStore store(encoder);

store.addDocument("doc1", "Machine learning is a field of AI.");
store.addDocument("doc2", "Neural networks are used in deep learning.");

auto results = store.retrieve("What is AI?", 2);
for (const auto& [score, doc] : results) {
    std::cout << "ID: " << doc->id << ", Score: " << score << std::endl;
}

const Document* doc = store.getDocument("doc1");
if (doc) {
    std::cout << doc->text << std::endl;
}

store.removeDocument("doc2");
store.clear();
```

---

## Error Handling

- **Throws `std::invalid_argument`** for duplicate IDs, empty text, or invalid k.
- **Returns nullptr** for missing documents in `getDocument`.
- **Handles zero vectors** in cosine similarity by returning 0.0.

---

## Performance Characteristics

- **Embedding generation** depends on encoder speed.
- **Retrieval** is O(N) for N documents (linear scan, suitable for small/medium collections).
- **Indexing** by ID is O(1) via hash map.
- **Mean pooling** and similarity are O(d_model).

## Integration Patterns

- **RAG systems:** Use as a backend for retrieval-augmented generation pipelines.
- **Semantic search:** Power search endpoints for question answering or document lookup.
- **Metadata filtering:** Store and filter on document metadata for advanced queries.

---

## Limitations and Constraints

- **No persistent storage:** In-memory only; persistence must be implemented externally.
- **No ANN (approximate nearest neighbor):** Linear scan only; for large-scale retrieval, integrate with FAISS or similar libraries.
- **No concurrent modification:** Not thread-safe for concurrent writes.
- **Assumes encoder output shape [seq_len, d_model] and mean pooling is appropriate.**
